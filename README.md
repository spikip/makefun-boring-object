## About this entry

The dullest everyday object is the rubber band, and the review has
to be funny and true at the same time. This entry gives it five
stars, which is already a joke, because nobody reviews a rubber
band. Then it says the band has held the reviewer's life together
since 1998, which is true in the most literal sense: rubber bands
hold papers, cables, vegetables, and entire junk drawers together
for decades. The final turn is that it asked for nothing, not even
a thank-you, which makes the band the most reliable and least
appreciated worker in the house. The observation is true, the
object is genuinely boring, and the laugh lands inside one line.
It stays well inside the two hundred character cap. The program
holds the line, checks it against that cap, and writes it to
/output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line review to `/output/entry.txt`.
